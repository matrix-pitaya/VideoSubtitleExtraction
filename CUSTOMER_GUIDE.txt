视频文案工作台 · Windows 便携版

一、启动
适用于 Windows 10 / 11 64 位电脑，建议 8GB 及以上内存。
完整解压 ZIP 到有写入权限的文件夹，例如 D:\视频文案工作台。
不要在压缩包中直接运行；不要放在系统受保护目录。
双击“打开视频文案工具.cmd”，浏览器会自动打开本地工作台。
自带 Python、运行依赖和 small 识别模型，无需安装 Python 或首次下载模型。
首次启动只是打开操作页面，点击“开始 / 重试未完成视频”才开始识别。
重复点击启动入口不会重复创建服务。关闭浏览器不等于停止服务。
使用完毕可双击“停止视频文案工具.cmd”。

二、处理与交付
创建订单 → 批量上传视频 / 填写本地文件夹 / 粘贴分享链接 → 加入订单。
默认 small、CPU、中文、口播文案模式。点击开始，逐条处理。
口播识别在本机完成。本地视频识别无需联网；平台链接下载需要联网。
无口播 / 只有背景音乐的视频应留空；自动识别仍可能有误，需要人工校对。
校对标题、文字和字幕时间后保存，点击“生成交付包”，再下载 ZIP。
Excel 仅包含编号、标题、文案；Word 有标题导航和分段正文；有文案的视频附 SRT / TXT。
下载失败项目不加入客户交付包，交付前请核对视频数量。
链接下载的临时媒体在该条处理结束后自动删除；上传文件和本地原文件不删除。

三、平台支持与实际限制
抖音、小红书、bilibili 已有真实样例下载和识别记录，但平台改版、删除、私密或失效链接仍会失败。
微信聊天中的视频请先保存为文件，再导入。
微信视频号目前尚未验证免登录完整下载：匿名分享接口可能只返回封面。
可点击“扫码登录视频号下载”，在独立 Edge / Chrome 窗口里登录腾讯元宝后尝试。
登录凭证仅存本机 data/auth，可通过工具清除；首次需本机已安装 Edge 或 Chrome。
元宝登录后的真实视频下载仍待验收；不承诺视频号全部链接可用，额外加密媒体暂未支持。
画面文字 OCR 需要手动选择，可能识别商品包装、水印和重复内容，请校对。
本包自带 small 模型。更大模型会额外下载并占用磁盘，默认 CPU 模式可直接使用。

四、数据与维护
data 文件夹保存自己的订单和处理结果；不要将自己的 data/auth 发送给其他人。
如需换电脑，备份 data 中订单数据；登录凭证建议在新电脑重新登录。
启动失败可查看 data/server.stderr.log。反馈日志时注意隐藏自己的链接或个人信息。
本软件依赖第三方开源组件；相应许可证保留在 runtime/Lib/site-packages 的元数据目录及 runtime/LICENSE.txt，版本清单见 THIRD_PARTY.json。
本包不含提供者的客户订单、视频、转写内容或登录凭证，不需要连接提供者后台。
