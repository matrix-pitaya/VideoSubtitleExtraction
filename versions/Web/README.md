# 视频文案工作台

此目录是 Web 版本的完整开发目录，包含应用源码、测试、启动脚本，以及本机运行环境、模型和订单数据。以下开发命令均在本目录执行。

本地部署的接单工具，使用 Streamlit + faster-whisper + yt-dlp。批量音视频口播转写，逐句校对，输出 Excel、Word、SRT、TXT 和 ZIP。订单状态保存在 `data/`，重启后可继续未完成任务；失败项目单独重试，成功项目跳过。

当前链接提取仅支持抖音、B站、小红书，其他平台链接在导入时跳过。旧订单中其他平台的记录保留，但不会参与重试；本地音视频文件继续支持。

## Windows 启动

客户便携包使用独立的 Python 3.12 Windows x64 嵌入式运行环境、自带依赖和 small 模型。解压后双击「打开视频文案工具.cmd」即可，无需安装 Python 或下载默认模型；「停止视频文案工具.cmd」关闭这个文件夹启动的服务。详细限制见 `CUSTOMER_GUIDE.txt`。便携包自动选择空闲端口，支持中文和空格目录，与开发环境的 8501 服务可以同时运行。

### 构建便携交付包

在已安装本项目依赖的 Python 3.12 环境中，准备 Python 官方 `python-3.12.10-embed-amd64.zip`，确保 `models/small` 已下载，然后运行：

```powershell
.\.venv\Scripts\python.exe build_delivery.py --runtime-zip build-cache/python-3.12.10-embed-amd64.zip --output ../Windows/builds/新版本目录
```

构建器只复制明确允许的应用源文件、已安装依赖的必要文件和四个模型文件，不复制 `.venv` 整体、订单数据、登录凭证或 Git 历史。第三方许可证保留在依赖目录，Whisper 模型许可证单独附带。输出包含 ZIP、文件校验清单和 SHA256。新构建交付文件保存在相邻的 `../Windows/builds/`，不会自动推送大文件到 GitHub。当前属于可独立运行的源码便携包，没有授权码、代码加密或付费激活功能。

Web 开发环境双击 **打开Web.cmd**：服务未启动时会在后台启动，随后用默认浏览器打开页面；已启动时直接打开，不重复启动。新电脑首次使用请先按下方步骤运行 `start.ps1` 安装环境。

**视频文案工具网址.url** 仅打开网址，适合本地服务已运行的情况。

安装 Python 3.11 或 3.12（含 Python Launcher），在本目录 PowerShell 执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

浏览器访问 http://127.0.0.1:8501 。首次安装依赖和首次加载模型需要网络。默认 small + CPU，无独立显卡也可运行。中文质量要求高时选 medium / large-v3，速度和内存需求更高。CUDA 模式需自行安装与 CTranslate2 兼容的 NVIDIA 运行库，失败时使用 CPU。

普通本地媒体通过 PyAV 解码，一般无需另装 FFmpeg；部分网络下载协议和媒体处理仍需要系统 FFmpeg。

### 首次模型下载失败

`ConnectError / WinError 10013` 是下载连接被阻止，切换 CPU 不会解决。在 `versions/Web` 目录运行：

```powershell
.\.venv\Scripts\python.exe download_models.py --model small
```

下载到 `models/small` 后，工具会优先从本地加载该模型，不再需要访问模型 Hub。其他模型需分别下载。如果下载命令仍失败，请检查防火墙或代理是否允许此 Python 进程联网。

## 接单步骤

1. 按客户名称创建订单。
2. 上传多个文件、填写本地文件夹，或粘贴多条含链接的分享文案。大视频建议用本地文件夹，扫描顶层文件，处理时请勿移动原文件。
3. 开始批量处理。单条失败不影响其他视频；修复网络、Cookies 或文件问题后再次点击处理。
4. 在校对表中修正标题、文字和时间，保存。BGM / 无口播视频文案留空；也可人工确认无口播并清空错误结果。修改后重新生成交付包。
5. 下载客户交付 ZIP：Excel 只有「编号、标题、文案」三列；Word 使用标题导航和分段正文；有内容的视频附独立 `.srt` / `.txt`。不附来源、状态、处理记录或本地路径，无口播条目不生成空字幕文件。
6. 未处理及下载失败项目不纳入客户交付包，仍保留在订单工作台，交付前应检查。

链接下载的临时媒体（含下载残片）在每条任务处理结束后自动删除，无论成功或失败。文案和字幕继续保留，重试时重新下载。上传文件与本地文件夹中的原文件不会删除；若程序被强制关闭，尚未执行清理的临时文件会在该条任务再次处理结束时清理。

## 平台边界

- 抖音：分享链接、视频页链接以及带 modal_id 的链接先走专用分享解析器，自动获取媒体并下载；失败后尝试 yt-dlp 备用路径。下载成功后与本地视频共用转写和导出流程。私密、已删除、图文作品及访问受限内容仍可能失败。
- 小红书：专用移动分享页解析，支持短链接、作品页和含 redirectPath 的登录跳转链接，保留分享签名参数。已用实际订单链接验证下载、口播转写和临时媒体清理。删除、私密、失效链接及访问受限作品仍可能失败，可填写登录 Cookies。
- B站：使用 yt-dlp 解析 bilibili.com 视频页与 b23.tv 分享短链接，已用实际订单样例完成下载和转写。登录限制、付费、删除或区域限制内容可能失败。
- 本地文件：不依赖原平台，要求有可解码的音轨。
- 默认只提取口播。无口播或只有 BGM 的视频显示「无口播」，文案留空，不自动切换 OCR。画面文字 OCR 必须手动选择，可能识别到包装、水印或重复文字，需要校对；每秒抽帧的字幕时间近似。
- Word 和 Excel 将口播字幕合并成正文段落；完全没有标点的转写使用基础断句规则补标点，不进行内容改写。SRT 保留逐句时间轴。自动标点、人名、数字和专业术语仍需人工校对，不保证营销宣传中的 99% 准确率。
- 不自动提取贴文描述或改写营销文案。

Cookies 是本机 Netscape 格式文件路径，应用不主动读取浏览器登录信息。只处理有权访问的内容。`data/` 包含客户媒体和文案；交付记录含来源和本地路径，分享前可删除 JSON。服务只监听本机，不宜直接开放公网。订单管理为单人本地模式，暂不支持多人并发操作同一订单。上传同名文件会去重，重名不同视频建议改名或使用文件夹导入。

## 验证

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

单元测试验证导出内容、SRT 时间精度、失败隔离、恢复状态和链接提取；真实语音准确率及平台下载需要用客户样例另行验收。
