## 真机验收待办

当前用户只有安卓手机，没有 iPhone。需取得近期 iPhone 和可获得旧 iPhone，记录型号、iOS、Safari 和闲鱼版本。在独立可信 HTTPS 测试入口运行免费短样例，再选取相册导出的 MP4、MOV/HEVC、音频、无口播及损坏文件。

分别验证首次模型下载、刷新后缓存、WebGPU 的实际推理和 WASM 回退、后台/锁屏中断、取消重试、TXT/SRT 保存到“文件”和系统分享。记录峰值内存如能测量、设备退出/发热和失败码。Windows WebKit 不支持某编解码器时的结果不能外推到真机。

闲鱼内置浏览器单独测试；失败时复制链接到 Safari，不承诺自动跳转。手机 `127.0.0.1` 不指向电脑。局域网普通 HTTP 和忽略证书错误不能用于本原型的正式验收；HTTPS 测试入口须与维护方协调，当前未部署到生产。
