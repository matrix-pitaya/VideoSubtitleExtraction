# 平台版本分类

各版本均以客户设备独立运行为目标，不依赖运营者的云服务器。平台链接下载需要联网；本地模型识别在客户设备上执行。

| 目录 | 当前状态 | 用途 |
| --- | --- | --- |
| Web | 可用 | 双击 `Web/打开Web.cmd` 启动本地工作台，使用浏览器操作 |
| Windows | 可用便携包 | 客户解压后双击启动；尚未开发独立窗口版 |
| macOS | 未开发 | 预留 Mac 软件工程和交付文件位置 |
| Android | 未开发 | 预留本地识别 Android 软件工程和 APK 位置 |
| iOS | 未开发 | 预留本地识别 iOS 软件工程及签名交付文件位置 |

现有源代码、运行环境、模型和订单继续位于项目根目录，避免改变工作台的数据路径。Web 目录提供统一启动入口；Windows 目录存放最新三个平台版的客户 ZIP 和 SHA256 校验文件。`build-cache/` 存放构建便携包需要的官方 Python 运行时 ZIP；`dist/` 是可重新生成的打包临时目录，不作为当前客户交付版本。

本地服务是在自己的电脑上运行的程序，不是云服务器。当前支持抖音、B站、小红书链接，以及本地音视频。
