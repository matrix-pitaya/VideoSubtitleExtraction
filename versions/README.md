# 平台版本分类

各版本均以客户设备独立运行为目标，不依赖运营者的云服务器。平台链接下载需要联网；本地模型识别在客户设备上执行。

| 目录 | 当前状态 | 用途 |
| --- | --- | --- |
| Web | 可用 | 双击 `Web/VideoSubtitleExtraction.cmd` 启动本目录的完整 Web 工程，使用浏览器操作 |
| Windows | 可用桌面试用包 | 客户解压后双击 EXE，在独立窗口中使用 |
| Browser | 实验原型，手机真机待测 | 可选 small / medium，在设备 Worker 本地识别；暂不收费 |
| macOS | 未开发 | 预留 Mac 软件工程和交付文件位置 |
| Android | 未开发 | 预留本地识别 Android 软件工程和 APK 位置 |
| iOS | 未开发 | 预留本地识别 iOS 软件工程及签名交付文件位置 |

应用源代码、测试、运行环境、模型、订单和构建脚本统一位于 `Web/`，开发命令在该目录执行。Windows 目录存放客户交付包，新的构建输出位于 `Windows/builds/`。`Web/build-cache/` 存放官方 Python 运行时 ZIP；`Web/dist/` 为历史打包临时产物。

本地服务是在自己的电脑上运行的程序，不是云服务器。当前支持抖音、B站、小红书链接，以及本地音视频。
