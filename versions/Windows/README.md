# Windows 版本

状态：已可用便携包，支持 Windows 10 / 11 x64。独立窗口版尚未开发。

最新交付文件：`builds/20261011-project-name/VideoSubtitleExtraction-Windows-x64.zip`，同目录附 `SHA256.txt`。旧的中文名称 ZIP 是历史版本。

将 ZIP 发送给客户。客户完整解压后双击「VideoSubtitleExtraction.cmd」，即可使用本地工作台。自带运行环境和 small 模型，支持抖音、B站、小红书链接，以及本地音视频。

不依赖你的后台，不含你的订单或登录凭证。客户使用过程会在自己的解压目录生成数据。ZIP 大文件仅保存在本机，不加入 GitHub 源代码仓库。
