# 分阶段实施及部署边界

## A：当前原型

独立 Browser 静态源码、固定 small/medium 模型、WASM Worker、免费样例、单文件本地识别、简体校对、TXT/SRT/DOCX/XLSX、诊断和测试报告。已完成本机自动化，安卓、iPhone 及闲鱼内置浏览器的完整真机验收仍待进行。large-v3 加载失败后暂缓。没有账户、付款、兑换码、后台接口、任务上传，也未变更生产服务器。

先收集红米 K50 Pro 的系统/浏览器版本及报告，再补低配置安卓、近期 iPhone 和可获得旧 iPhone。真实录像、口音、噪声、无口播、长到上限和内置浏览器需要进一步验证。若速度、内存或质量不足，缩小支持范围，再评估独立按量云端回退；不把识别移到现有小服务器。

## B：轻量授权（尚未实现）

建议首先按有效期授权，服务端生成安全随机兑换码、只存哈希、唯一约束和原子兑换；短期会话、限速、吊销、独立管理鉴权和脱敏日志。刷新、换设备、退款和丢失凭据规则须明确。有效码清单及签名私钥不能进入前端。若增加额度，任务预占/完成/释放幂等；前端识别成功、分钟或设备标识均可伪造，不能用于严格可靠计费。

拟议接口仅为评审草案：`POST /api/v1/redeem` 接受兑换码并返回短期凭证和 browser 产品权益；`GET /api/v1/entitlements` 验证凭证并查询有效期；管理接口独立鉴权生成、吊销及导出卡券。请求不得含媒体、识别文字或本地文件路径。具体凭证格式与数据库事务在阶段 B 定义，没有现成可用 API 或密钥。

以既有服务器实测剩余内存决定单进程、小连接池、有限日志和负载上限，优先评估复用基础设施，避免无必要新增 MySQL/Redis 实例；独立数据库权限，不触碰闲鱼业务表。

## 测试部署与回滚计划

当前仅本机 127.0.0.1:5174。`npm run build` 生成独立 `dist/`，须附固定模型和 runtime，并配置 Vite 所列安全响应头或等效配置。代码禁止远程模型回退，所有浏览器网络请求只指向同一站点。部署时模型 MIME、WASM MIME `application/wasm`、Worker JS 模块 MIME、CSP 及子目录相对路径须再测。

正式移动端需要可信 HTTPS。公网 HTTP/IP 不满足本原型安全上下文要求；IP 地址可评估可信 IP 证书及续期，并非天生不能 HTTPS。不能用“忽略证书错误”做验收。方案和现有 443 使用情况由服务器维护方确认，先独立测试入口，保留原网站和闲鱼后台配置、根目录、数据、端口。

模型静态托管或对象存储/CDN 的成本需估算：100 次首次模型下载约 4.36GB（十进制），还要加运行组件、页面和缓存丢失的重复下载；客户端计算不等于零服务器成本。当前默认运行脚本复制全部固定 ORT 运行组件以供不同后端测试，静态产物包含未必被请求的文件和构建器输出的副本；原型交付体积不等于每位用户的首次实际网络量，上线前进一步收敛资产。

建议以完整版本目录发布，页面、运行库、固定模型保持一致；记录文件摘要，先验证独立入口，再切换指向新版本的静态映射。回滚切回上一完整版本，模型缓存按版本命名隔离，不清理其他产品数据。小模型上限、首次/缓存性能、下载保存、网络隐私和权限需在该入口重复验证。
