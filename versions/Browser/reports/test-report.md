## 功能及异常验收

0.1.0 初始自动化为 14 项通过、10 项按范围跳过。0.1.1 新增图库/28MiB 视频及 base 检查后，20 项有效检查累计全部通过，另 10 项按范围跳过。初次有 5 项因测试脚本的 50MiB 内存传参上限及把 Edge 自带下载面板统计为网页请求而失败；改用本地文件路径及只检查 HTTP(S) 请求后，全部 5 项重跑通过。明细见最新 JSON 的 automatedTestSummary，此为完整运行及针对性复验的汇总。跳过项为重复移动视口下的桌面专用 HTTP/WebGPU/存储故障测试，不代表真机通过。Browser 单元 5 项、共享 Python 协议 3 项、原 Web 回归 22 项全部通过。

- 免费中文样例实推理，单文件中文路径、重复导入、校对前禁用导出；UTF-8 TXT 及毫秒 SRT 下载内容正确，桌面下载文件已读取。手机分享和“下载/文件”落盘还需用户验证。
- 本机 Edge 的 MP4/MOV AAC-LC、MP3/WAV 提取成功。WebKit 模拟的系统解码未能支持 AAC/MP3，呈现 `FORMAT_UNSUPPORTED`，WAV 可运行。没有伪造视频提取成功；没有默认装全量 FFmpeg WASM。真实 MOV/HEVC 与 iPhone 相册文件尚未测。
- 无音轨返回 `NO_AUDIO`，损坏 MP4 返回 `MEDIA_INVALID`，近静音为空，无效 WAV 拒绝。BGM 正弦波产生了“我不要再回我了”的幻觉，必须校对且可手动清空；**没有实现可靠的自动无口播/BGM 分类器**。
- 29.28 秒跨 20 秒分段产生时间偏移正确、有限且不重叠的结果；识别文本仍有重复、扩写及错字。边界去重和合法时间码不代表字幕内容准确，仍需更广自然语音测试。
- 大于 100 MiB 禁止开始（0.1.0 为 25 MiB）。历史 0.1.0/0.1.1 拒绝超过 60 秒文件，0.1.2 已改为预计解码内存预算，详情见下文。没有测得手机实际峰值内存，也没有承诺不会被手机系统回收。
- IndexedDB 缓存刷新后模型下载 0 字节（不代表页面/运行库零请求）。故意损坏缓存的 config.json 后仅重新下载 2,243 字节。缺失模型为 `MODEL_MISSING`，同尺寸篡改摘要为 `MODEL_INTEGRITY`，均不进入推理。
- 通过故障注入测试存储不可用和配额写入失败：提示并使用本次内存模型。此为注入测试，不是实际耗尽手机磁盘；模型 revision 用命名空间隔离；0.1.1 已测试 tiny/base 切换释放 Worker、重新验证及各自摘要，未来更新至新提交版本仍需重测。
- 取消终止 Worker，随后样例可重试；后台通过 visibilitychange 故障模拟中断并保留已显示分段。真实锁屏/后台、系统强杀和手机常亮失效仍待测；刷新不恢复任务，阶段 A 无任何扣费。
- localhost 为真实安全上下文。另用本机响应映射到非 loopback HTTP 测试域，浏览器实际 `isSecureContext=false`，页面显示 `HTTPS_REQUIRED` 且禁用样例；未绕过安全标志或证书。公网 IP 可信 HTTPS 的配置与续期尚未部署验收。
- 浏览器自动化观察到的页面请求只指向本站，均为 GET/HEAD、无请求体、无上传。CSP 限制同源，模型 Hub 远程回退禁用。诊断 JSON 无导入文件名、音视频或识别文字；报告中的候选文本只属于自制样例。没有进行手机或整系统级网络抓包，真机网络隐私需补验。

### 0.1.4 固定 small/WASM 与 Office 导出

按用户要求，当前模型注册表仅允许 small（约 240 MiB）；主线程固定 WASM 和 small，不提供自动/WebGPU、tiny/base 入口。Worker 在读取模型前拒绝其他模式/模型，停止请求 GPU 适配器。不会为了通过样例而偷偷降级小模型。small 与 PC 默认模型规模相同，浏览器量化、引擎及解码参数仍不同，因此不承诺所有音视频准确或与 PC 同等速度。手机此前的 tiny 成功不能当作 small 真机验收。

新增本地 DOCX 与 XLSX 导出，组件按需从本站加载，不提交文案。Word 为编号加标题（Heading 1）和分段正文，Excel 仅编号/标题/文案三列、冻结表头、自动换行。生成的文件经过真实下载后解包/读取检查，并验证简体中文、编号、标题及正文。用户确认无口播时 Office 导出文案为空；TXT/SRT 仍不可导出空分段。Excel 单格超过 32767 字符显示错误，提示改用 Word/TXT，避免悄悄截断。

修复 small 大权重单次 IndexedDB 写入失败：权重按 32 MiB 存储分块，在同一事务提交清单与全部分块，读取重组后仍按固定文件 SHA256 校验。兼容历史 ArrayBuffer 缓存。桌面 Edge、安卓视口 Edge、iPhone 视口 WebKit 均验证刷新后 251,846,613 字节缓存命中、模型下载 0 字节；这不是手机磁盘配额或系统回收测试。

三环境的定向端到端检查全部通过（3 个综合用例），覆盖固定配置、取消/后台后直接重试、简体 TXT/SRT、实际 DOCX/XLSX、无口播 Excel、持久缓存和无 POST 上传；单元 7 项及构建通过。记录见 `office-test-summary-0.1.4.json`。手机 WPS/Office 实际打开、iPhone 文件落盘及 small 性能仍待用户真机复验。原 Web/Windows 和生产服务器未修改。

新增 4 个桌面 Edge 检查全部通过：Worker 在下载前拒绝 WebGPU/auto/tiny/base、缓存损坏后按摘要重下、存储不可用及写入配额不足仍可在本次内存中识别。后二者为注入故障，不能当作实际手机内存/磁盘压力结果；记录见 `model-storage-test-summary-0.1.4.json`。加上三环境综合用例，本轮共 7 个端到端用例通过，无失败。

### 0.1.5 medium 与计算设置整理

模型选择器现为 small（默认/最低）和 medium；与 PC 提供的同名模型规模对应，但浏览器引擎、量化、线程及解码参数仍不同。计算模式固定 WASM，移除原来不可操作的下拉框，改为静态文字。选择模型本身不下载；切换会终止旧 Worker 并要求重新跑实际短样例，不暗中回退 tiny/base。手机的历史 tiny 成功不代表 small/medium 已在真机通过。

medium 权重固定 Xenova 提交，优化后总计 778,897,618 字节（742.8 MiB）。原编码器还声明了 24 个大型注意力输出，首次实际运行因内存失败；仅请求 last_hidden_state 仍未解决。现用标准库脚本移除这些未用于转写的 GraphProto.output 字段，保留所有节点和权重张量字节，原始和派生 SHA256 均固定并再次校验。三个转换脚本测试通过；本机原生 ONNX 对原始/优化 medium 的零输入比较，1,536,000 个 last_hidden_state 值最大绝对差为 0。这是一个一致性夹具，不是一般准确率测量。

medium 已在本机 Edge 的 WASM 实际识别 7.32 秒中文短样例，忽略标点后与参考文字一致；最新时间和缓存记录见 `medium-measurements-0.1.5.json`。单个合成样例不能证明歌曲、其他口音或真实客户视频准确，也不能代表手机性能。模型加载复验使用只读模型字节响应避免巨型 Response 副本；IndexedDB 按 32 MiB 分块逐次写入，最后发布清单，读取仍完整 SHA256 校验。配额不足继续给出警告，不能保证每台手机都能存下模型。

large-v3 已下载并通过摘要校验，优化后约 1.46 GiB，但浏览器加载实测失败（ENGINE_FAILURE / Failed to fetch，伴随缓存写入警告）；后续尝试未得到有效识别结果。按用户要求暂停，已从界面和模型注册表移除，直接 Worker 请求也拒绝，不计为支持模型。失败记录见 `large-v3-failed-benchmark-0.1.5.json`；下载权重移到本机忽略的 artifacts，不进入当前构建。原 PC 版本的 large-v3 没有改动。

本轮仍仅为本机原型，原 Web/Windows 和生产服务器未修改。iPhone 真机、红米 small/medium 性能与手机 Office 文件打开仍待验证。

本轮定向端到端共 9 项全部通过：桌面 Edge 的 6 项实际识别、模型策略、存储故障及综合导出检查；桌面 Edge、安卓视口 Edge、iPhone 视口 WebKit 的 3 项模型切换/无计算下拉框检查。综合用例确认 small 刷新后模型下载 0 字节、251,846,613 字节缓存命中，取消/后台中断后可重试，实际读取四种导出内容，且无 POST 上传。单元 8 项、编码器图转换 3 项及构建通过。记录见 `model-and-export-test-summary-0.1.5.json`，模拟视口不是手机实测。
